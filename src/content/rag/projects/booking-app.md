# booking-app: Full-Stack Reservation & Appointment System

## Overview
A production-ready reservation and appointment scheduling platform built with Next.js 15, Drizzle ORM, and serverless infrastructure.

## Core Features
- **Appointment Scheduling**: Real-time slot availability checking, booking management, and cancellation logic.
- **Serverless Database & Rate Limiting**: Powered by Neon Serverless PostgreSQL with Drizzle ORM, backed by Upstash Redis for API rate limiting.
- **Automated Alerts & Calendar Sync**: Integrated with Twilio SMS API for automated SMS reminders and Google Calendar API for calendar synchronization.

## Tech Stack
- **Framework**: Next.js 15, React 19, TypeScript, Tailwind CSS.
- **Database & Cache**: Neon Serverless Postgres, Drizzle ORM, Upstash Redis.
- **Integrations**: Twilio SMS API, Google Calendar API.
