# Complete List of Ayush Saha's Projects

Ayush Saha has developed 6 major production-ready projects and AI systems:

1. **PRism (PR Prep)**: An autonomous GitHub App and web platform that automates pull request code reviews using 4 parallel AI specialists (Security, Code Quality, Tests, Docs) with LangGraph orchestration, hybrid vector retrieval (`pgvector`), and human-in-the-loop approval queues.
2. **Eval_MCP**: A single-binary Model Context Protocol (MCP) evaluation server built natively in Go for prompt evaluation, RAG scoring, regression detection, and embedded dark web dashboard. Exposes 16 native MCP tools.
3. **IntelliDocs**: An enterprise-scale Retrieval-Augmented Generation (RAG) system featuring multi-agent query orchestration (Planner, Router, Retriever, Synthesizer, Validator), hybrid FAISS + BM25 search, NVIDIA neural reranking, and SSE streaming.
4. **TestaCode (AI-Test-Gen)**: An autonomous AI-powered test generation suite for Python, JavaScript, TypeScript, and Java. Features AST parsing, multi-stage LLM chains, syntax auto-correction retries, and session isolation.
5. **booking-app**: A full-stack reservation and appointment scheduling platform built with Next.js 15, Drizzle ORM, Neon Serverless PostgreSQL, Upstash Redis rate limiting, Twilio SMS alerts, and Google Calendar API.
6. **FiTrack**: A cross-platform mobile fitness tracking application built with React Native, MobX state management, Firebase authentication, and MMKV fast local storage.
