# FiTrack: Cross-Platform Mobile Fitness Tracker

## Overview
An all-in-one mobile fitness tracking application built with React Native for tracking workouts, active metrics, goals, and nutrition.

## Core Features
- **Mobile Workflow**: Built with React Native and MobX for reactive global state management.
- **Fast Local Storage & Auth**: Utilizes MMKV for ultra-fast key-value local storage and Firebase Authentication for secure user sign-in.
- **Automated Mobile Release Builds**: Configured for automated release pipelines and cross-platform mobile performance.

## Tech Stack
- **Framework**: React Native, TypeScript.
- **State & Storage**: MobX, MMKV storage.
- **Backend & Auth**: Firebase Auth.
