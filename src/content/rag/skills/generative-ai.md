# Generative AI & Autonomous Agentic Systems

## Technical Specializations
- **Retrieval-Augmented Generation (RAG)**: Advanced hybrid dense-sparse retrieval (FAISS, Qdrant, BM25), Reciprocal Rank Fusion (RRF), NVIDIA Neural Reranking, context compression, HyDE question generation, and chunk enrichment.
- **Agentic AI & Orchestration**: Autonomous multi-agent pipelines using LangGraph and custom stateful agents (Planner → Router → Retriever → Synthesizer → Validator).
- **Model Context Protocol (MCP)**: Native Go and Python MCP server development (`Eval_MCP`), exposing tool suites for automated evaluations and workspace integrations.
- **LLM Prompt Engineering & Guardrails**: Structured outputs, hallucination detection, asynchronous validator agents, human-in-the-loop (HITL) review gates, and KV prompt caching optimizations.
- **Open-Source & Cloud LLMs**: Integration with Google Gemini Flash models (`gemini-1.5-flash`, `gemini-2.0-flash`), OpenRouter, Cerebras, Ollama, and local open-source models.
