# About Ayush Saha

## Bio & Profile
Ayush Saha is an AI Engineer and 4th-year Computer Science student at **Siliguri Institute of Technology (SIT), West Bengal**. He specializes in building AI-driven products, Retrieval-Augmented Generation (RAG) knowledge systems, autonomous multi-agent pipelines, and production-ready codebases.

## Projects Built by Ayush Saha
Ayush Saha has created 6 major projects:
- **PRism**: GitHub App and AI code review engine built with FastAPI, LangGraph, and pgvector.
- **Eval_MCP**: Single-binary Go Model Context Protocol evaluation server with 16 native tools.
- **IntelliDocs**: Enterprise Multi-Agent RAG knowledge assistant with FAISS + BM25 search and SSE streaming.
- **TestaCode (AI-Test-Gen)**: Autonomous AI test generator for Python, JS/TS, and Java with AST parsing.
- **booking-app**: Full-stack reservation system with Next.js 15, Drizzle ORM, Neon Postgres, and Twilio SMS.
- **FiTrack**: Cross-platform React Native fitness tracking app with MobX and Firebase.
